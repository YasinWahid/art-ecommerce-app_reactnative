# 🎨 Artsello – React Native E-Commerce App for Art Products

Artsello is a mobile e-commerce application built with **React Native** and **Firebase**, designed for artists to showcase and sell their handmade and digital art products. The platform supports both admin and user roles with separate functionalities for product management, shopping, and user moderation.

---

## 🚀 Features

### 🔐 Authentication
- Firebase login and registration system
- Role-based access control (Admin / User)

### 👤 Admin Panel
- Block and unblock users
- Delete any product from the platform

### 🛍️ User Experience
- Drawer navigation with:
  - Categories (Clothing, Jewelry, Pottery, Photography, Paintings, Scarves, Sculptures, Instruments)
  - About Us & Privacy Policy
- Home screen:
  - Artsello logo with user profile picture
  - Welcome image slider
  - Category cards for navigation
- Product Browsing:
  - Grid view of products by category
  - Add products to favorites (wishlist)
  - Product detail page:
    - Title, description, price, image
    - "Add to Wishlist" and "Contact Seller" buttons
    - Customer reviews and ratings

### 👥 User Profile
- My Listings (edit/delete personal products)
- Add New Product
- View Favorite Products
- Settings
- Logout
